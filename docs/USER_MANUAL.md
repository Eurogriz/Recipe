## 1. Введение

### 1.1. Назначение

**Formulation Workbench** — enterprise-приложение для работы с **верифицированной** базой рецептур лакокрасочных материалов (ЛКМ) и строительной химии. Приложение обеспечивает:

- Хранение **только проверенных** рецептур с обязательной библиографической ссылкой
- Прогнозирование свойств (плотность, сухой остаток, VOC, PVC, Tg, HSP)
- Генерацию технологических карт в формате PDF
- Интеграцию с 1С:Предприятие 8.x через CommerceML 2.0

### 1.2. ⚠ Дисклеймер

> Данные носят **справочный характер**. Перед промышленным применением требуется:
> 1. Лабораторная валидация
> 2. Адаптация под конкретное сырьё
> 3. Тестирование готового продукта на целевой подложке

Все **расчётные значения** в приложении помечены символом ⚠ и подразумевают обязательное экспериментальное подтверждение.

### 1.3. Поддерживаемые категории

| Категория | Подтипы |
|---|---|
| **Лаки** | Алкидные, ПУ, НЦ, акриловые, эпоксидные, УФ-отверждаемые |
| **Краски** | Водно-дисперсионные, масляные, алкидные, силикатные, силиконовые, эпоксидные, ПУ |
| **Колеры** | Универсальные, водные, органоразбавляемые |
| **Клеи** | ПВА, цианоакрилатные, эпоксидные, ПУ, контактные, термоплавкие, MS-полимерные |
| **Герметики** | Силиконовые, акриловые, ПУ, тиоколовые, бутиловые, MS-полимерные |
| **Мастики** | Битумные, битумно-полимерные, каучуковые, акриловые |
| **Грунтовки, шпатлёвки, штукатурки, наливные полы** | Различные |
| **Спецпокрытия** | Антикоррозионные, огнезащитные, гидроизоляция |

## 2. Установка

### 2.1. Системные требования

| Параметр | Минимум | Рекомендуется |
|---|---|---|
| **ОС** | Windows 10 (build 19041+) | Windows 11 |
| **RAM** | 8 ГБ | 16 ГБ |
| **Диск** | 500 МБ | 1 ГБ |
| **Монитор** | 1920×1080 | 2560×1440 или 4K |
| **DPI** | 100% | 150% / 200% |

### 2.2. Установка приложения

1. Запустите `FormulationWorkbench-1.0.0-setup.exe`
2. Следуйте инструкциям инсталлятора
3. Выберите папку установки (по умолчанию `C:\Program Files\FormulationWorkbench`)
4. Завершите установку
5. Запустите приложение через меню Пуск или ярлык на рабочем столе

### 2.3. Первоначальная настройка

При первом запуске приложение запросит:
1. **Пароль для шифрования БД** — используется для SQLCipher (AES-256). **Запомните его!** Без него данные невозможно восстановить.
2. **Salt для Argon2id** — генерируется автоматически, сохраняется в `%APPDATA%`.

## 3. Быстрый старт

### 3.1. Главное окно

После запуска откроется главное окно с тремя областями:

```
┌─────────────────────────────────────────────────┐
│ [≡] Меню  [Toolbar: Найти, Калькулятор, ...]     │
├──────────────┬──────────────────────────────────┤
│  Каталог     │  Редактор рецептуры              │
│  (слева)     │  (справа, 7 вкладок)             │
│              │                                  │
│  [Фильтры]   │  [Общие] [Состав] [Технология]  │
│  [Таблица]   │  [Характеристики] [Применение]  │
│              │  [Безопасность] [Источники]      │
├──────────────┴──────────────────────────────────┤
│ [Статус: Готово]                                │
└─────────────────────────────────────────────────┘
```

### 3.2. Поиск рецептуры

1. Введите название, ингредиент или описание в поле поиска (сверху слева)
2. Применятся фильтры по категории и классу
3. Дважды кликните на строке для загрузки рецептуры в редактор

**Горячая клавиша:** `Ctrl+K` — открыть Command Palette для быстрого поиска.

### 3.3. Создание новой рецептуры

1. `Ctrl+N` или меню **Файл → Новая рецептура**
2. Заполните обязательные поля:
   - Категория
   - Подкатегория
   - Тип связующего
   - Назначение
3. Добавьте стадии состава (кнопка **+ Стадия**)
4. Добавьте компоненты (кнопка **+ Компонент**)
5. Укажите первичный источник на вкладке **Источники**
6. **Сохраните** (`Ctrl+S`)

## 5. Работа с рецептурами

### 5.1. Структура рецептуры

Каждая рецептура содержит:

- **Общие сведения**: категория, подкатегория, связующее, класс
- **Состав** (одна или несколько стадий):
  - Стадия 1: Премикс (низкоскоростное перемешивание)
  - Стадия 2: Диспергирование пигментов (высокоскоростное)
  - Стадия 3: Ввод связующего
  - ...
- **Технология**: оборудование, температура, скорость, длительность, контрольные точки
- **Источники**: обязательный первичный + опциональные кросс-референсы

### 5.2. Правила верификации

Каждая рецептура проходит трёхступенчатую верификацию:

```
Draft → PendingReview → Verified (3 подтверждения)
```

| Статус | Описание | Видна в каталоге? |
|---|---|---|
| **Draft** | Черновик, редактируется | ❌ (видна только Admin) |
| **PendingReview** | На ревью | ❌ (видна только Admin) |
| **Verified** | Подтверждена 3 независимыми ревьюерами | ✅ |
| **Rejected** | Отклонена | ❌ |

**Важно:** Verified рецептуры — **иммутабельны**. Любое изменение создаёт новую версию.

### 5.3. Сравнение рецептур

1. Выберите 2-4 рецептуры в каталоге (зажмите `Ctrl`)
2. Меню **Вид → Сравнить рецептуры** (`Ctrl+Shift+C`)
3. Откроется side-by-side сравнение по составу, процессу и свойствам

## 6. Калькуляторы

### 6.1. Калькулятор партии

**Назначение:** Масштабирование рецептуры на любую массу/объём партии.

**Использование:**
1. Откройте рецептуру
2. Меню **Вид → Калькулятор партии**
3. Введите целевую массу (кг) или объём (л)
4. Получите таблицу с количествами каждого компонента

**Пример вывода:**

| Компонент | Масс.% | Масса, кг | Объём, л |
|---|---|---|---|
| Water | 28.85 | 28.85 | 28.85 |
| Titanium dioxide | 22.0 | 22.00 | 5.20 |
| Acrylic emulsion | 32.0 | 32.00 | 30.48 |
| ... | ... | ... | ... |
| **ИТОГО** | 100.0 | **100.00** | **75.59** |

### 6.2. PVC / CPVC калькулятор

**Назначение:** Расчёт объёмной концентрации пигмента и определение класса блеска.

**Выходные данные:**
- PVC (%)
- CPVC (%)
- PVC/CPVC ratio
- Класс блеска: Gloss / Semi-gloss / Matte / Deep matte

**⚠ Advisory:** Значения рассчитаны по эвристическим формулам (Asbeck-Van Loo). Для критичных применений требуют лабораторной валидации.

### 6.3. Калькулятор Tg (Fox)

**Назначение:** Расчёт температуры стеклования смесей полимеров по уравнению Fox.

**Формула:** 1/Tg_mix = Σ(wᵢ / Tgᵢ)

**Входные данные:** Tg каждого полимера в составе (можно задать вручную).

### 6.4. Калькулятор HSP (Hansen)

**Назначение:** Оценка совместимости полимеров и растворителей через Hansen Solubility Parameters.

**Выходные данные:**
- RED (Relative Energy Difference) — <1: совместимы, >1: не совместимы
- Лучший растворитель для данного полимера

### 6.5. Rule of Mixtures

**Назначение:** Расчёт density, mass/volume solids, VOC по правилу аддитивности.

**Выходные данные:**
- Плотность (г/см³)
- Сухой остаток по массе (%)
- Сухой остаток по объёму (%)
- VOC (г/л) — по EU Directive 2004/42/CE (вода НЕ считается VOC)

## 7. Прогноз характеристик (ML-advisory)

### 7.1. Что прогнозируется

ML-модель на основе scikit-learn RandomForest прогнозирует:

- Scrub resistance (cycles, ISO 11998)
- Adhesion class (ISO 2409)
- Gloss 60° (GU)
- Contrast ratio
- Density (если не рассчитано аналитически)

### 7.2. ⚠ КРИТИЧЕСКОЕ ПРЕДУПРЕЖДЕНИЕ

> **Все ML-прогнозы помечены символом ⚠ "advisory hint, not measured".**
>
> Перед использованием прогнозных значений в критичных применениях
> (производственный допуск, сертификация) **требуется лабораторное подтверждение**.

ML-модель обучена на верифицированном датасете ≥500 рецептур, но имеет ограничения:
- Ограничена классами рецептур в обучающей выборке
- Чувствительна к составу сырья (региональные различия)
- Не учитывает aging и storage effects

### 7.3. Confidence score

Каждый прогноз сопровождается оценкой уверенности (0..1):

- **0.9+** — высокая уверенность (типичный рецепт, много обучающих примеров)
- **0.7-0.9** — средняя уверенность
- **<0.7** — низкая уверенность, требует дополнительной проверки

## 8. Экспорт данных

### 8.1. PDF — Технологическая карта

`Ctrl+E` или меню **Файл → Экспорт в PDF**

PDF содержит:
- Шапку с метаданными рецептуры
- Полный состав по стадиям (с CAS-номерами)
- Параметры процесса (T, об/мин, время, контрольные точки)
- Полные библиографические ссылки
- Обязательный юридический дисклеймер

### 8.2. XLSX (Excel)

Меню **Файл → Экспорт в Excel**

Формат: одна строка на рецептуру, столбцы — основные поля. Удобно для анализа и построения отчётов.

### 8.3. CSV

Меню **Файл → Экспорт в CSV**

Универсальный формат для импорта в другие системы (1С, SAP, Excel).

### 8.4. JSON

Меню **Файл → Экспорт в JSON**

Полный дамп рецептуры со всеми полями, audit log, версиями.

## 9. Интеграция с 1С

### 9.1. Экспорт в 1С (CommerceML 2.0)

Меню **Файл → Экспорт в 1С**

Формат: XML CommerceML 2.0. Импортируется в 1С:Предприятие 8.x как:
- Номенклатура (товар)
- Спецификация (состав)
- Технологический процесс

### 9.2. Импорт справочника сырья из 1С

CLI команда: `formulation-import-1c --input <xml-файл>`

Импортирует номенклатуру сырья из выгрузки 1С в локальную БД.

## 10. Верификация и качество данных

### 10.1. Источники

Каждая запись должна иметь **минимум один первичный источник** с указанием:
- Авторы
- Название
- Год издания
- Издательство
- ISBN / DOI (если есть)
- Страница или номер формуляции

**Рекомендованные источники:**
- Ernest W. Flick — серия "Industrial Formulations" (Noyes Publications)
- Zeno W. Wicks Jr., Frank N. Jones, S. Peter Pappas — "Organic Coatings"
- Artur Goldschmidt, Hans-Joachim Streitberger — "BASF Handbook"
- Edward M. Petrie — "Handbook of Adhesives and Sealants"
- Sina Ebnesajjad — "Adhesives Technology Handbook"
- ГОСТ, EN/ISO, ASTM, DIN стандарты
- Технические бюллетени BASF, Evonik, Wacker, Dow, Allnex, Arkema, Covestro, Byk, Tego

### 10.2. Workflow верификации

```
Технолог создаёт рецептуру (статус: Draft)
       ↓
Технолог отправляет на ревью (статус: PendingReview)
       ↓
Ревьюер 1 подтверждает (verifications: 1)
       ↓
Ревьюер 2 подтверждает (verifications: 2)
       ↓
Ревьюер 3 подтверждает → авто-переход в VERIFIED
       ↓
Рецептура появляется в основном каталоге
```

### 10.3. Audit Log

Каждое изменение фиксируется в audit log:
- Кто изменил
- Что изменил
- Когда (timestamp)
- Контекст (комментарий)

Просмотр: правый клик на рецептуре → **История изменений**

## 11. Часто задаваемые вопросы

### 11.1. Забыл пароль БД — что делать?

⚠ **Пароль невозможно восстановить**. Пожалуйста:
1. Создайте новую БД (`formulation-init-db`)
2. Импортируйте seed-датасет заново
3. Заведите свои рецептуры повторно

**Рекомендация:** Регулярно делайте бэкапы БД в `%APPDATA%\FormulationWorkbench\` на внешний носитель.

### 11.2. Почему мои рецептуры не видны в каталоге?

Возможные причины:
1. Статус = Draft или PendingReview → видны только Admin/Auditor
2. Не указан первичный источник → рецептура не проходит верификацию
3. Не пройдена тройная верификация → статус не Verified

Решение: проверьте статус (`Ctrl+I` → История).

### 11.3. Насколько точны расчётные значения?

**Rule-based калькуляторы** (density, mass solids, VOC):
- Density: ~3% погрешность (отлично для архитектурных решений)
- Mass solids: ~15% погрешность (приемлемо для предварительных оценок)
- VOC: ~15-30% погрешность (требует проверки для регуляторных отчётов)

**ML-advisory прогнозы:**
- Confidence 0.7+ — надёжны для предварительной оценки
- Confidence <0.7 — требуют лабораторного подтверждения

**Во всех случаях:** перед использованием в production обязательна лабораторная валидация.

### 11.4. Как обновить версию рецептуры?

Verified рецептуры **иммутабельны**. Для изменения:
1. Откройте рецептуру
2. Меню **Правка → Создать новую версию**
3. Внесите изменения в новой версии
4. Сохраните и отправьте на повторную верификацию

### 11.5. Где хранятся данные?

- **БД:** `%APPDATA%\FormulationWorkbench\formulation.db` (зашифрована SQLCipher)
- **Логи:** `%LOCALAPPDATA%\FormulationWorkbench\logs\`
- **PDF-кеш:** `%LOCALAPPDATA%\FormulationWorkbench\pdf-cache\`
